# fe-angular-css-starter

A minimal **Angular (standalone components) + TypeScript + plain CSS** starter for DayZer0 frontend briefs.

## Stack

- Angular 20 (standalone components, no NgModules)
- TypeScript (strict)
- Plain, hand-written CSS — no UI framework

## Getting started

```bash
npm install
npm start
```

Then open http://localhost:4200. You should see the "It runs" starter screen.

To produce a production build:

```bash
npm run build
```

Output lands in `dist/app`.
